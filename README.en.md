## 🚀 What I Build

My work centers on the **`k6` ecosystem** and **AI engineering evaluation**:

* **⚡ `k6` performance and automation engineering**
  * **[`k6auto`](https://github.com/Mistyrain520/k6auto)**: An automation and performance testing toolkit built around `k6` and Go extensions (`xk6`). It connects API orchestration, custom assertions, multi-protocol extensions, and observability reporting, making the same foundation reusable for functional regression and high-concurrency load testing.
  * **[`k6eval`](https://github.com/Mistyrain520/k6eval)**: Extends `k6auto`'s high-concurrency execution and metrics capabilities into **AI / LLM evaluation**, enabling batch evaluation, latency and throughput testing, and stability validation for model services, conversational workflows, and agents.
  * **[`k6ai-attack`](https://github.com/Mistyrain520/k6ai-attack)**: Explores quality evaluation and observability pipelines for LLM applications, including multi-turn conversation evaluation, prompt regression, and output-quality scoring. It also applies red teaming to test the boundaries and safety of AI applications under complex interactions.
