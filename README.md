## 🚀 核心体系与正在构建的项目

围绕 **`k6` 生态**与 **AI 工程化评测**，我主要聚焦在以下几个方向：

* **⚡ `k6` 性能与自动化工程体系**
  * **[`k6auto`](https://github.com/Mistyrain520/k6auto)**：基于 `k6` 与 Go 扩展（`xk6`）构建的自动化与性能测试实践方案，打通接口编排、自定义断言、多协议扩展与可观测性报告，兼顾功能回归与高并发压测复用。
  * **[`k6eval`](https://github.com/Mistyrain520/k6eval)**：将 `k6auto` 的高并发执行与指标统计能力延伸至 **AI / LLM 评测领域**，用于对大模型服务、对话工作流与 Agent 进行批量评测、延迟/吞吐压测及稳定性验证。
  * **[`k6ai-attack`](https://github.com/Mistyrain520/k6ai-attack)**：探索大模型应用的质量评估与可观测性链路（如多轮对话评测、Prompt 回归、输出质量打分），结合对抗性测试（Red Teaming）验证 AI 应用在复杂交互下的边界与安全性。
